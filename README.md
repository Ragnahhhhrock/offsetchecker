# Offsetcheck

**Keeping the bankers honest.**

Independent verification of banks' offset-account and home-loan interest calculations — [offsetcheck.com](https://offsetcheck.com)

## Contents

- `brand/` — the Offsetcheck brand system (single source of truth)
  - `brand/Offsetcheck-Brand-Style-Guide.pdf` — full style guide (v1.0)
  - `brand/style-guide.md` — machine-readable version for tooling/agents
  - `brand/assets/` — logo kit (SVG masters + PNG renders, favicon)

## Rules

All collateral and assets must comply with the brand style guide. Logo files are used as-is from `brand/assets/` — never re-typeset, recolour, stretch, or rebuild the logo.
